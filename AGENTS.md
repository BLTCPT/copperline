# Copperline contributor playbook
Clean-room industrial pricing workbench. Synthetic examples only. No affiliation or compatibility claim with Pricefx, GridCraft, ArtCraft, or any industrial company.
Read docs/architecture.md, docs/status.md and docs/security.md. Keep the deterministic money/model/pricing crates free of filesystem, networking, UI and clocks. Every business mutation goes through Engine::execute; UI and CLI share commands. Do not panic, unwrap, expect, use unsafe, or silently repair invalid data. Bound inputs and use checked money math. A failed command must leave memory and durable state unchanged. Never discard a corrupt committed revision.
Before commits run cargo xtask ci. Include regression tests for financial, approval, data loss and crash fixes. All assets original; update ATTRIBUTION.md. Never read proprietary implementation or import vendor artwork. No external writes, deploy, repository creation or publishing without user authorization. Windows runtime is only verified on Windows.
