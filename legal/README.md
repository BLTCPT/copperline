# Dependency notices and provenance

`THIRD_PARTY_NOTICES.txt` includes all 313 external packages in `Cargo.lock`, a superset of any one platform's linked dependencies. It is generated from checksum-verified `.crate` archives and exact official upstream supplements. `notice-coverage.json` records every included file hash. The workspace's nine original packages are MIT licensed under the root `LICENSE`.

Regenerate with Python 3.11+ and the Cargo registry archives already cached:

```sh
python scripts/dependency_notices.py
python scripts/dependency_notices.py --check
```

For a new development environment, `cargo fetch --locked` populates Cargo's normal cache. The generator itself runs `cargo metadata --locked --offline`, makes no network requests, extracts no files from archives, and executes no downloaded code. `--check` compares generated bytes without modifying files. Unknown missing notices, changed archive/supplement checksums, stale mappings and unsafe paths fail the command.

`upstream-sources.json` maps omitted crate notices to official repositories at the `.cargo_vcs_info.json` commit recovered from each checksum-verified archive. The corresponding documents under `upstream/` are unchanged, including original whitespace. `standard-sources.json` pins the official SPDX MIT text supplied alongside upstream license declarations; its template attribution line remains unfilled. It does not invent package copyright holders. Original font texts include `Hack-Regular.txt`, `OFL.txt`, `UFL.txt` and the emoji icon font MIT notice. The r-efi `AUTHORS` documents include their full MIT permission/warranty text and copyright attribution; their alternative license expressions remain recorded.

## Outstanding upstream limits

- **dispatch 0.2.0, MIT:** its published archive and pinned upstream tree declare MIT and author Steven Sheldon, but provide no crate-specific copyright/license notice in a root file, nested license directory, README or source header. The exact published `Cargo.toml.orig` declaration/author metadata and unchanged official MIT text are included. Attribution completeness is not certified; no author or copyright line has been manufactured.
- **Ten newer objc2-family packages:** the exact upstream `LICENSE.md` files declare MIT or `Zlib OR Apache-2.0 OR MIT` and discuss uncertainty concerning Apple SDK-derived bindings. The full declarations and caveats are preserved verbatim, with unchanged standard MIT text supplied separately. This review does not resolve that upstream legal question. Exact package/version mappings appear in `notice-coverage.json` under `upstream_legal_caveat`.

`python scripts/dependency_notices.py --check --require-complete` deliberately fails while the dispatch attribution gap remains. A successful ordinary `--check` confirms deterministic evidence and documented gaps, **not** complete licensing clearance. Source notices, optional dependencies and binary distribution obligations are different scopes. These files are evidence for review, not a legal conclusion or a claim that prototype status removes redistribution obligations.
